# Vote Simulator

두 지역구에서 같은 득표수가 나올 확률을 계산하고 시각화하는 GitHub Pages용 정적 웹앱입니다.

## 기능

- 관측 득표수와 상대 표를 바탕으로 베타분포를 설정합니다.
- 후보 득표수와 상대 득표수의 합계를 각 지역구 총투표수로 자동 적용합니다.
- 베타-이항 분포의 동일 득표수 확률을 정확 계산합니다.
- 몬테카를로 시뮬레이션의 누적 일치 비율을 애니메이션으로 보여줍니다.
- 득표수 분포, 동일 득표 기여도, 총투표수 변화에 따른 확률을 시각화합니다.

## GitHub Pages

별도 빌드 과정이 없습니다. 저장소 루트의 `index.html`을 GitHub Pages에서 바로 배포하면 됩니다.
